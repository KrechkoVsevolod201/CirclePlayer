# CirclePlayer v1.6

## Что нового

- Более плавная навигация по спискам и прокрутка Click Wheel без пропуска
  отдельных шагов.
- Увеличенные области нажатия кнопок Click Wheel и виброотклик каждой кнопки.
- Палитра HSV для выбора цвета темы; применение цвета не перерисовывает весь
  плеер на каждом кадре перетаскивания.
- Улучшена синхронизация выделенного трека и Play/Pause при выходе из списка.
- Кэш обложек альбомов и снижение лишней работы при анимации скретча.
- Подготовлены локализованные описания приложения, политика конфиденциальности
  и настройки релизной подписи.
- Целевая версия Android обновлена до API 36.

## Установка и публикация

Подписанные сборки: [APK](https://github.com/KrechkoVsevolod201/CirclePlayer/raw/refs/heads/master/release-assets/CirclePlayer-v1.6.apk)

## English

- Smoother track browsing and Click Wheel input with one queued selection per
  wheel detent.
- Larger Click Wheel touch targets and haptic feedback for every wheel button.
- HSV color palette with local drag preview to avoid updating the full player
  on every pointer event.
- Play/Pause selection is synchronized when leaving the track list.
- Album-art caching and fewer per-frame allocations during vinyl scratching.
- Store listing metadata, privacy policy, and release-signing setup prepared.
- Target SDK updated to API 36.
