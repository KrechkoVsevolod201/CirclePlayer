# CirclePlayer v1.5

## Что нового

- Пользовательский звук прокрутки Click Wheel.
- Тонкая настройка масштаба элементов плеера отдельно для портретного и альбомного режимов.
- Ручная скорость винила и синхронизация скорости с BPM-тегом текущего трека.
- Четыре пары светлой/тёмной цветовых тем, редактор цветов и сохранение/импорт/экспорт пресетов JSON.
- Выбор русского или английского интерфейса.
- Улучшенный контраст выбранных состояний и плавные переходы интерфейса.
- Оптимизация чтения медиатеки, шкалы прогресса, Click Wheel и realtime аудиоэффектов.

## Установка

Скачайте `CirclePlayer-v1.5.apk` из раздела Assets этого GitHub Release и установите APK на Android 7.1 или новее.

> APK собран конфигурацией debug signing, как и локальный release build проекта. Это не ключ публикации Google Play.

## English

- Custom Click Wheel sound, independent portrait/landscape element scaling, manual vinyl speed and BPM synchronization.
- Four light/dark theme pairs with color editing and JSON preset save/import/export.
- Russian and English interface, improved state contrast and smoother transitions.
- Optimized media queries, progress updates, wheel gestures and realtime audio processors.

Download `CirclePlayer-v1.5.apk` from this release's Assets. The APK is signed with the project's debug signing configuration, not a Google Play publishing key.
